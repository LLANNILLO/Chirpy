# Chirpy

Chirpy is a small Twitter-like REST API written in Go. Users can sign up, log in with JWT access tokens and refresh tokens, post short messages ("chirps"), and upgrade to the premium **Chirpy Red** plan through a payment-provider webhook.

## Requirements

Before running Chirpy you'll need the following installed on your machine:

- **Postgres** — Chirpy stores users, chirps, and refresh tokens in a Postgres database.
- **Go** (1.25 or later) — needed to build and run the server.
- **[goose](https://github.com/pressly/goose)** — applies the database migrations in `sql/schema`.
- **[sqlc](https://sqlc.dev)** (optional) — only needed if you change the SQL queries and want to regenerate `internal/database`.

## Installing

Clone the repository and build the server:

```bash
git clone https://github.com/LLANNILLO/Chirpy.git
cd Chirpy
go build -o chirpy .
```

## Configuration

Chirpy reads its configuration from a `.env` file in the directory you run it from. Create it like this:

```env
DB_URL="postgres://username:password@localhost:5432/chirpy?sslmode=disable"
PLATFORM="dev"
JWT_SECRET="a-long-random-secret"
POLKA_KEY="your-polka-api-key"
```

| Variable | Description |
| --- | --- |
| `DB_URL` | Connection string for your Postgres database. |
| `PLATFORM` | Set to `dev` to enable `POST /admin/reset`. Any other value disables it. |
| `JWT_SECRET` | Secret used to sign access tokens (HS256). Generate one with `openssl rand -base64 64`. |
| `POLKA_KEY` | API key the Polka payment webhook must send to upgrade users. |

Create the database and apply the schema before starting the server:

```bash
createdb chirpy
goose -dir sql/schema postgres "$DB_URL" up
```

## Running

Start the server from the project root (it listens on port `8080`):

```bash
./chirpy
```

Try the main flow with `curl`:

```bash
# Create a user
curl -X POST localhost:8080/api/users \
  -d '{"email": "alice@example.com", "password": "secret"}'

# Log in and get an access token + refresh token
curl -X POST localhost:8080/api/login \
  -d '{"email": "alice@example.com", "password": "secret"}'

# Post a chirp
curl -X POST localhost:8080/api/chirps \
  -H "Authorization: Bearer <access_token>" \
  -d '{"body": "Hello, Chirpy!"}'
```

## API

Endpoints marked 🔒 require an `Authorization: Bearer <token>` header.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/healthz` | Health check. Returns `OK`. |
| `POST` | `/api/users` | Create a user (`email`, `password`). |
| `PUT` | `/api/users` 🔒 | Update the current user's email and password. |
| `POST` | `/api/login` | Log in. Returns a 1-hour access token and a 60-day refresh token. |
| `POST` | `/api/refresh` 🔒 | Exchange a refresh token for a new access token. |
| `POST` | `/api/revoke` 🔒 | Revoke a refresh token. |
| `GET` | `/api/chirps` | List chirps. Optional query params: `author_id=<uuid>`, `sort=asc\|desc`. |
| `GET` | `/api/chirps/{chirpID}` | Get a single chirp. |
| `POST` | `/api/chirps` 🔒 | Create a chirp (max 140 characters, profanity is masked). |
| `DELETE` | `/api/chirps/{chirpID}` 🔒 | Delete a chirp. Only its author can delete it. |
| `POST` | `/api/polka/webhooks` | Polka webhook. Requires `Authorization: ApiKey <POLKA_KEY>`. Upgrades a user to Chirpy Red on `user.upgraded`. |
| `GET` | `/admin/metrics` | HTML page with the number of hits on `/app/`. |
| `POST` | `/admin/reset` | Delete all users and reset metrics (`PLATFORM=dev` only). |

For `/api/refresh` and `/api/revoke`, the bearer token is the **refresh token**, not the access token.

## Project structure

| Path | Contents |
| --- | --- |
| `main.go` | Configuration loading, routing, and server startup. |
| `handler_*.go` | HTTP handlers, one file per endpoint. |
| `public` | Static files served under `/app/`. Nothing outside this folder is exposed. |
| `internal/auth` | Password hashing (Argon2id), JWT creation/validation, refresh tokens, header parsing. |
| `internal/database` | Type-safe query code generated by sqlc. |
| `sql/schema` | goose migrations. |
| `sql/queries` | SQL queries consumed by sqlc. |
